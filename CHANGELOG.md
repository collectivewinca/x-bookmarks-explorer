## [1.0.0] - 2026-11-03

### Added
- Initial release of X/Twitter bookmarks explorer
- 200 curated bookmarks from @shinydiscobear
- 6 categories: Design & Code, Game Development, Vibe Coding, Security, Terminals, Other
- Client-side filtering by search, category, author
- Sort options: Date (Newest/Oldest), Likes (High/Low), Bookmarks (High/Low)
- Grid/List view toggle
- Responsive design with dark theme
- Cards with author avatars, text preview, media images, and engagement metrics
- All data embedded inline (no fetch required)

### Technical
- Pure HTML, CSS, JavaScript (no frameworks)
- Git repository initialized
- Published to https://fierce-scroll-7bsr.here.now/
